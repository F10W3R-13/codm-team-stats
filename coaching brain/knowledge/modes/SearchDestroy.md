# Search & Destroy

> bomb plant/defend. 라운드제, 리스폰 없음. CODM 모드 중 가장 언어 의존적.

---

**목표**: bomb plant/defend. 라운드제, 리스폰 없음.

**코치가 강조한 핵심**:
- 마이크로 소통 필수 (모드 중 가장 언어 의존적)
- IGL 중심 (현재 팀: Cartels) — decisive calls 양호, 더 vocal해지면 좋음(전사문 5)
- 플랜트 후 홀드 포지션
- 언어 장벽이 가장 치명적 (Shisui 진입 콜 문제)
- **SMG의 commit 부족(전사문 5)**: Cartels는 balanced, Shisui는 aggressive하지만 hill-toward(키라캐처), Jason은 aggressive pushing SMG지만 LMG 종종 사용
- **Maozin의 유연성(전사문 5)**: 팀이 충분히 밀지 못할 때 본인이 빠른 역할을 자처하는 사고방식 제안

**흔한 실수**:
- Shisui 진입 콜 부재 → 타이밍 미스
- Cartels 혼자 사이트 홀드 → flank 취약
- 팀 전체가 너무 느림 — operator 있을 때 위축(전사문 5)

## 레인 투자 구조 — LoL 저글러 모델 (★ 전사문 9 신규)

> 코치가 SnD의 레인 구조를 **리그 오브 레전드에 비유**해 설명. 팀의 인원 배치 = 레인 투자.

- **구조**: 3레인(A/B/mid) + 로밍(저글). 팀은 메타·밴플에 따라 특정 레인에 인원을 집중 투자한다 (예: B레인 3명 + mid 정보용 1명 → **A레인 완전 고립**)
- **고립 레인 선수의 첫 임무 = 죽지 않기(not dying)**: 투자 받지 못한 레인에서 죽지 않으면, 투자 레인 3명이 게임을 굴린다 (LoL에서 탑이 버티면 바텀+저글이 캐리하는 것과 동일)
- **단, 상대 push는 예측 가능**: 상대도 가치를 만들어야 하므로 고립 레인을 밀어온다(합리적 push). 이건 "예상해야 하는 것"
- **충분한 가치를 얻었으면 도망쳐라(run away)**: 다른 레인에서 가치를 얻었다면, 최약 레인(A)에서 상대가 가치를 회수하게 두지 마라 — "우리는 다른 레인에서 충분히 얻었으니 나는 도망친다"
- 핵심 질문: "내 레인은 투자 레인인가, 고립 레인인가?" → 고립이면 생존이 1순위, 킬이 아님

## 위치 노출과 유틸 운용 (★ 전사문 9 신규)

- **CODM SnD에서 위치 노출은 큰 불이익이 아니다**: Valorant와 달리 A↔B 로테이션이 빠르고, 스나이퍼 위치는 어차피 예측됨 → 오히려 **A러시 카운터로 총성을 내어 위치를 알려주면** 적이 원샷 공포 때문에 A러시를 주저한다
- **스나이퍼는 pre-fire로 공포심을 조성하라**: 미드에 있더라도 모든 것을 pre-fire해서 "저 스나이퍼가 무섭다"는 인식을 만들어라
- **네이드는 리테이크용으로 아껴두자**(팀 논의): 초기 진입에 네이드 소진 금지

## 맵별 메모

### Raid
- 소통 on point였음 (긍정 사례) — 전사문 3
- Sparrow 사용 가능(팀원 의견) — 코치는 "raidad sparrow는 상상 안 됨" — [Standoff B](../maps/Standoff.md) 한정으로 제안 유지

### Tunisia (★ 전사문 9)
- **A러시 카운터**: A 사이트에서 총을 쏴서 소리를 들려 위치 노출 → 적 A러시 위축. 노출 비용 < A러시 허용 비용
- A 사이트 각 자체가 그렇게 좋지 않음 ("not that good of an angle")

### Firing Range (★ 전사문 9)
- **A 사이트 리테이크가 다른 맵보다 쉬움**: A 단순 + shower/barrel 양쪽 핀치 가능
- 문제: 현재 A 방어 시 네이드 밸류가 0 → 플랜팅 타이밍을 맞춰 **네이드로 A 폭격**하는 리테이크 설계 (라인업이 쉬운 맵이라 가능)
- 적이 심기 전에 너무 빨리 죽는 경향 관찰됨
