# 지식 상태 확인

지식베이스의 현재 상태를 종합적으로 보고한다. "내가 지금 어디까지 정리했더라?"가 궁금할 때 사용한다.

## 절차

### 1단계: INDEX와 로그 읽기
- `knowledge/INDEX.md`를 읽는다.
- `knowledge/log/흡수로그.md`를 읽는다.

### 2단계: 파일 구조 스캔
- `knowledge/` 디렉토리 아래의 모든 .md 파일 목록을 확인한다.
- 각 파일의 줄 수를 확인한다 (큰 파일은 잠재적 분할 후보).
- `reference/` 디렉토리도 확인한다.

다음 명령을 사용하라:
```bash
find "C:/Users/0616y/Downloads/Superpowers Workspace/knowledge" "C:/Users/0616y/Downloads/Superpowers Workspace/reference" -name "*.md" -exec wc -l {} \; | sort -rn
```

### 3단계: 보고

다음 형식으로 보고한다:

```
## 📊 지식베이스 상태

### 버전 & 메타
- 버전: vX.X
- 마지막 갱신: YYYY-MM-DD
- 기반 전사문: 1-N

### 흡수 이력
| 전사문 | 주요 기여 | 상태 |
|---|---|---|
| 1 | 원칙 2,3,6 — Combine HP | ✅ |
| 2 | 원칙 4 — 무기 메타 | ✅ |
| ... | ... | ✅ |

### 파일별 크기
| 파일 | 줄 수 | 비고 |
|---|---|---|
| principles/코칭철학원칙.md | 211 | (가장 큼 — 원칙 응집) |
| maps/Combine.md | XX | |
| ... | | |

### 커버리지
- 맵 풀: HP 5/5 ✅, SnD 1/5 (Raid만), Control 3/3 ✅
- (INDEX의 "보완 필요 영역" 체크리스트 기준)

### 보완 필요 (INDEX 체크리스트에서)
- [ ] 항목 1
- [ ] 항목 2
- ...

### 추천 다음 행동
- (보완 필요 항목 중 우선순위가 높은 것 제안)
```

## 주의사항
- 이 명령은 **읽기 전용**이다. 파일을 수정하지 마라.
- 파일의 **줄 수**는 토큰 효율의 지표다. 한 파일이 300줄을 넘으면 분할을 고려할 수 있다고 제안하라.
- 보완 필요 항목이 너무 많으면, 우선순위를 제안하라 (다음 전사문에서 다뤄질 가능성이 높은 것 등).
