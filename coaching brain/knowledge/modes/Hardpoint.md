# Hardpoint

> 고정된 힐 포인트를 점령하여 시간을 쌓는 모드. 250점 선착.

---

**목표**: 고정된 힐 포인트를 점령하여 시간을 쌓는다. 250점 선착.

**코치가 강조한 핵심**:
- 스폰은 경향이지 정답 아님 — P1 점령 자체가 회전의 핵심(전사문 5)
- 언덕 안에서 가치 창출 (cycling out 금지) — slay out은 hill control 전제 하에만(전사문 5)
- 회전 타이밍 (특히 다음 money hill로 일찍)
- 힐마다 중요도 다름 (money hill 존재)
- "shoulder to shoulder" 정렬
- **첫째/둘째 P3의 전술 교차(전사문 6)**: 첫째 P3은 스폰 잡기, 둘째 P3은 적이 스폰 대비하므로 정면 강제 + operator로 밀기
- **P4 첫 웨이브 방어(전사문 6)**: 가장 먼저 회전한 선수는 바깥이 아닌 **언덕 안**에서 첫 웨이브 방어 — 미드 선수는 타이밍 의존적이라 읽기 어려움
- **operator sacrifice/promise 시스템(전사문 6)**: operator 켜면 누군가가 희생 진입 — 사전 합의된 약속으로 매번 콜 불필요
- **OBJ 생존이 언덕의 생명줄(전사문 8)**: OBJ가 challenge하다 일찍 죽으면 AR이 포지션 버리고 언덕으로 → 회전 불리. "이기고 있을 때 더 안 죽기"
- **Pause의 가치(전사문 8)**: 2-3킬 후 low면 push 말고 pause(코너 프론/숨기) — "annoying > invincible". adrenaline rush 경고
- **War Machine은 teammate와 물리적 push(전사문 8)**: 창밖으로 던지지 말고 동료와 같이 밀며 각을 지워라. suppression은 기본 제공 — 가치는 push 파워에 있음
- **세 가지 기본(전사문 8)**: helping · pausing · not dying. 매핑·게임플랜 이전에 **습관** 체화 선행
- **AR의 가치 = 힐 안 생존(전사문 9)**: AR이 힐 안/근처에서 살아서 각도(head glitch)를 들고만 있어도 적은 그 각도를 피해 움직임 → SMG가 힐로 접근할 공간이 생김. Hurricane 메타(3-tap chest)라 헤드글리치 피킹 자체가 위협. **"힐 근처에서는 특히 패시브하게"**
- **War Machine 첫 라이프 금지(전사문 9)**: 첫 진입 시도엔 오퍼레이터 금지, **두 번째 진입부터** 사용. 첫 시도에 죽어도 OK → 리스폰 후 오퍼레이터로 리테이크/디펜드(그때쯤 힐 30-40초 남아 충분한 가치). 첫 웨이브는 상대가 트로피+오퍼레이터 방어 준비된 예측 가능 순간이라 선사용 = 무가치 소실. 오퍼레이터 킬은 보너스 점수 → 스코어스트릭 파밍으로 이어짐
- **옐로 스폰 과대평가 경계(전사문 9)**: 좋은 스폰(yellow)은 가치지만 **혼자 open peek으로 잡으려 하지 마라**. 나쁜 스폰으로도 힐 홀드 가능하다고 믿으면 shoulder peek으로 존재감만 보여 시간을 벌면 된다 — 팀메이트가 올 때까지. "100% 확신 없이(팀 도움 없이) 좋은 스폰에 집착 금지"
- **엔트리 시 침착한 각도 피킹(전사문 9)**: 적 위치를 가정하고 따라가지 말고, 본인이 편한 각(stair head glitch 등)에서 **공정한 교전**을 만들고 한 명씩 피킹. 점프 인 같은 더티워크는 SMG(Cartels/Jason/NXL) 담당 — 킬이 중요하지 진입이 먼저가 아니다

**흔한 실수**:
- Deep spawn 맹신 → 언덕 본체 소홀
- Cycling out → 언덕 버리고 바깥 킬
- 단일 진입 ("too confident with gunfight")
- 킬 후 즉시 push (모멘텀 역전 위험)
- slay out을 hill control 없이 시도 → 가치 미미(전사문 5)
- 가장 먼저 회전한 선수가 혼자 다음 힐로 감 → 적에게 읽힘(전사문 5)
- 모든 각을 지키려 함 → 핀치에서 의도 붕괴(전사문 6)
- P4 첫 웨이브를 바깥에서 방어 → 적 진입 방향 읽기 어려움(전사문 6)
- OBJ가 challenge하다 죽음 → AR 포지션 붕괴 → 회전 disadvantaged 시작(전사문 8)
- 2-3킬 후 low인데도 adrenaline에 push → 가치 상실(전사문 8)
- "이기고 있다" 자각 없이 챌린지 → 자승자박(전사문 8)
- 기계력 우위가 인내심 빼앗음 → 과도한 challenge(전사문 8)
- 과도한 selfless(잘못된 타이밍 희생) → 가치 없는 죽음(전사문 8)
- 초기 각도 판단이 좋았는데 스스로 포기하고 힐 진입 우선 → 각도 피킹 가치가 진입보다 높아야(전사문 9, AR)
- 상대가 점프인 해야 할 문을 성급히 열어줌 → 진입 부담은 적에게(전사문 9)
- 운 없는 날 킬을 찾아 몸 던짐 → 킬 서칭 대신 모멘텀 빌딩+팀 공간 창출(전사문 9)
