## ZCode 맞춤 명령 4종 구현 계획

### 개요
지식베이스(`knowledge/`)를 활용하는 4개의 ZCode slash command를 만들어, AI 워크플로우 자동화를 구축한다.

### 명령 파일 위치
`C:/Users/0616y/Downloads/Superpowers Workspace/.zcode/commands/` (작업공간 스코프 — 이 작업공간에서만 작동)

### 4개 명령

#### 1. `/absorb` — 전사문 흡수
- **용도**: `/absorb 전사문7.md` → 전사문을 읽고 지식베이스에 자동 통합
- **절차**:
  1. 지정된 전사문 파일 읽기
  2. `knowledge/INDEX.md` 읽기 → 지식 구조 파악
  3. 전사문 분석: 핵심 통찰 추출, 분류 (철학/역학/맵지식/팀운영)
  4. 기존 파일들 읽어보며 어디에 통합할지 판단
  5. 해당 파일들에 새 내용 통합 (출처: 전사문 N)
  6. `log/흡수로그.md`에 한 줄 추가
  7. `INDEX.md`의 버전/기반 전사문 갱신
  8. 보고: 무엇을 어디에 추가했는지 요약
- **argument-hint**: `[전사문 파일명]`

#### 2. `/coach` — 코칭 질의응답
- **용도**: `/coach Combine P3 첫째/둘째 차이?` → AI가 관련 파일을 자동 탐색하여 답변
- **절차**:
  1. `knowledge/INDEX.md` 읽기 → 구조 파악
  2. 질문 분석 → 어느 파일(들)이 관련 있는지 판단
  3. 관련 파일들 읽기
  4. 지식 기반으로 답변 (원칙, 역학, 맵 전술 인용)
  5. 답변에 출처 파일 링크 표시
- **argument-hint**: `[코칭 질문]`

#### 3. `/status` — 지식 상태 확인
- **용도**: `/status` → 현재 지식 커버리지, 보완 필요 영역, 최근 흡수 이력 보고
- **절차**:
  1. `knowledge/INDEX.md` 읽기
  2. `log/흡수로그.md` 읽기
  3. 파일 구조 스캔 (어떤 파일이 있는지, 줄 수)
  4. 보고: 현재 버전, 흡수된 전사문 목록, 보완 필요 항목, 파일별 크기
- **argument-hint**: 없음

#### 4. `/vod` — VOD 리뷰
- **용도**: `/vod 상황 설명` → 지식베이스 기반으로 코치 관점 분석
- **절차**:
  1. `knowledge/INDEX.md` 읽기
  2. 상황 분석 → 관련 원칙/역학/맵 지식 판단
  3. 해당 파일들 읽기
  4. 코치 관점 분석: "이 상황에서 코치라면 이 원칙을 적용할 것"
  5. 개선 제안 + 관련 지식 링크
- **argument-hint**: `[VOD/상황 설명]`

### 파일 구조
```
.zcode/commands/
├── absorb.md    — 전사문 흡수
├── coach.md     — 코칭 질의응답
├── status.md    — 지식 상태 확인
└── vod.md       — VOD 리뷰
```

### 각 명령 파일 구조 (공통)
```markdown
---
description: "한글 설명 (슬래시 메뉴에 표시)"
argument-hint: "[인자 힌트]"
---

(프롬프트 본문 — $ARGUMENTS 또는 $1 포함)
```

### 구현 순서
1. `.zcode/commands/` 디렉토리 생성
2. 4개 명령 파일 작성
3. `/` 메뉴에서 명령이 보이는지 확인 (사용자가 직접)
4. 각 명령 테스트 (실제로 쳐보기)

### 범위 밖
- 옵시디언 플러그인 설치하지 않음 (길 A: ZCode 중심)
- RAG/벡터 검색 구축하지 않음 (나중 단계)
- 자동 감지(watch 폴더)하지 않음 — 명령을 쳐야 작동
- 복잡한 태그 시스템/MOC 구축하지 않음 (나중 단계)
