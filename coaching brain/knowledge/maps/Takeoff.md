## Hardpoint

★ v0.2 신규 (전사문 5) · v0.4 P1·P4 보강 (전사문 8)

| 힐        | 코치의 통찰                                                                                                                                                                                                                                                                                                                                                      | 출처       |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- |
| **P1** ★ | **OBJ 과도한 challenge가 회전 붕괴의 뿌리(전사문 8)**: 우리 OBJ가 "안 죽어도 될 때" challenge하러 나가서 죽음 → 적이 불안감 없이 언덕으로 → AR이 포지션 버리고 언덕으로 와야 → P2 회전이 disadvantageous position에서 시작. 코치의 진단: "적 Legacy는 fancy aimer가 아니지만 좋은 OBJ — 안 죽을 때 안 죽고 안 밀 때 안 민다. 반면 우리는 기계력이 좋아 challenge하고 죽는다." **해결**: OBJ는 언덕 안에서 chill — "we can just wait and try to chill inside of the OBJ more". 이기고 있을 때(언덕 점령 중)는 더 보수적으로. | 전사문 8    |
| **P1**   | **catwalk spawn 신뢰성 한계(전사문 8)**: catwalk 스폰을 잡고 있어도 적이 계속 섞여 스폰 — "완전히 reliable하지 않다". 스폰 통제에 집착하지 말고 **front 집중 + flank 경계**로 전환.                                                                                                                                                | 전사문 8    |
| **P3** ★ | **top red 최우선 — Combine P3과 동일 원칙(전사문 5)**: P3 잡으면 무조건 top red 먼저, 시간·공간 있을 때 특히. top red 통제 = P3 통제 용이. initial kill은 언덕 안 적(먼저 회전한 놈)부터 — stretch out 금지. **lounge 고정 금지**: lounge 위치에서 flank 너무 걱정 → 킬 후 hill 쪽으로 포지션(스폰 가까이 → 팀 관련성). **2nd P3 catwalk spawn(전사문 5)**: catwalk 스폰이 잡히면 피할 수 없는 상황(in-inevitable) — lounge 적의 움직임은 어느 정도 감수.             | 전사문 5    |
| **P4**   | **slay out은 hill control 후에(전사문 5)**: Takeoff P4에서도 킬 후 언덕 점수 확보되면 stretch out ok — 24/7 언덕 안 고집 아님.                                                                                                                                                                                                                                                        | 전사문 5    |
| **P4** ★ | **거점과의 연관성(전사문 7)**: Takeoff는 스폰이 "개 그지 같아서" 계속 거점 안에 있어야 — **나와 거점의 물리적 거리가 매우 가까워야 함**. 꼭 스텝인 안 해도 "연관성"이 지척이어야. 거점을 잘 밟아주면 적이 급격히 들어와도 대처 가능. 너무 여유 생겼다고 stretch out 안 하는 건 좋았음. **뇌정지 주의(전사문 7)**: 너무 많은 각을 보려는 것(=불안)이 Takeoff에서 특히 문제 — P1/P2/P3가 멀고 루트가 복잡해서 미리 빼는 옵스킬이나 다방향 피킹이 효율이 안 나옴. **해결**: 봐야 할 각 중 일부를 포기하고 안전 지대(벽 기대고 한쪽만 째는)에서 다시 시작할 것. | 전사문 5, 7 |
| **P4** ★ | **P4 = 70% operators(전사문 8)**: Claw·Equalizer·War Machine 세 개 다 모였어도 broken → operator "사용법 자체"가 문제. **War Machine은 teammate와 물리적 push**: 창문 밖으로 bullet만 던지지 말고, Exile처럼 동료가 push할 때 같이 밀며 가까운 각부터 하나씩 지우며 진행. suppression은 war machine의 built-in factor — 진짜 밸류는 **pushing power**에 있음. **trophy 대응**: 적이 trophy 깔면 bullet spam은 낭비 — 동료와 물리적 push로 각을 지워야 trophy 무력화. | 전사문 8    |
