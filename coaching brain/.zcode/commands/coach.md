# 코칭 질의응답

코치의 지식베이스를 활용하여 CODM 코칭 질문에 답한다. 이 명령은 AI가 INDEX에서 시작해 필요한 파일만 스스로 탐색하는 세컨드브레인의 검색 워크플로우다.

## 질문

$ARGUMENTS

## 절차

### 1단계: INDEX 읽기
- `knowledge/INDEX.md`를 읽는다.
- 이것이 지식베이스의 입구다. 전체 구조와 모든 파일의 위치가 여기에 있다.

### 2단계: 질문 분석 — 어느 파일(들)이 관련 있는가?

질문을 분석하여 필요한 파일을 판단한다. **INDEX에 있는 설명만으로 판단하라.** 파일을 다 열 필요는 없다.

**탐색 가이드:**

| 질문 유형 | 읽어야 할 파일 |
|---|---|
| "왜 그렇게 해야 하는가" / 원리 질문 | `principles/코칭철학원칙.md` |
| CODM이 어떻게 작동하는가 | `mechanics/CODM기본역학.md` |
| 무기/옵스킬 질문 | `mechanics/무기옵스킬메타.md` |
| 용어 정의 | `mechanics/공용어사전.md` |
| 모드 일반 전술 | `modes/{해당 모드}.md` |
| 특정 맵 전술 | `maps/{해당 맵}.md` |
| 팀 소통/역할 | `team/팀운영.md` |
| 공식 규칙/맵 풀/밴픽 | `reference/CODM_2026_Esports_Settings.md` |

**최소 파일 원칙**: 질문에 답하는 데 필요한 파일만 읽어라. 토큰을 아껴라. 1-3개 파일이면 충분한 경우가 대부분이다.

### 3단계: 관련 파일 읽기
- 판단한 파일(들)을 읽는다.
- 각 파일의 내용에서 질문에 답할 수 있는 근거를 찾는다.

### 4단계: 답변

다음 원칙으로 답변한다:

**답변 원칙:**
- **지식베이스 기반으로 답하라.** 코치의 원칙, 통찰, 전술을 인용하라. 일반적인 CODM 지식이 아니라 **이 코치의 철학**으로 답해야 한다.
- 코치의 원어 인용문이 있으면 그대로 가져와라.
- 답변에 **출처를 표시**하라: "(원칙 3 — 안에서 가치를 찾아라)" 또는 "(Combine P3, 전사문 5)" 식으로.
- 지식베이스에 답이 **없으면** 솔직히 말하라: "현재 지식베이스에 이 주제에 대한 내용이 없습니다. 전사문에서 다뤄지지 않았습니다."
- 보완 필요 영역(INDEX의 체크리스트 참조)에 해당하면 그 사실도 알려라.

**답변 구조:**
1. 핵심 답변 (1-2문장)
2. 근거 (코치의 원칙/통찰 인용)
3. 구체적 적용 (맵/모드 전술이 있으면)
4. 출처 파일 링크

## 주의사항
- 이것은 코치의 **대리인**으로 답하는 것이다. 코치의 목소리로, 코치의 철학으로 답하라.
- 하지만 코치가 직접 말한 것이 아님을 명심하라. "지식베이스 기준으로..."라는 점을 암묵적으로 유지하라.
- 추측하지 마라. 지식베이스에 있으면 답하고, 없으면 없다고 해라.
