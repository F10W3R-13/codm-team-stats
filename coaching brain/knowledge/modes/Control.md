# Control

> 사이트 캡처/방어. 티켓(생명수)제. 2026 풀: Raid, [Standoff](../maps/Standoff.md), [Crossroads Strike](../maps/CrossroadsStrike.md).

**목표**: 사이트 캡처/방어. 티켓(생명수)제. 2026 풀: Raid, Standoff, Crossroads Strike.

**코치가 강조한 핵심 (전사문 5)**:
- **"지지 않으려는" vs "이기는" 플레이 구분**: 티켓이 충분할 때 공격적으로 시도 — 버티다 죽는 것보다 트레이드 만들며 돌격해 죽는 것이 가치
- **능동적 공격 강제**: 모멘텀이 있든 없든 어느 시점엔 과감하게 밀어야 — 동료와 거리 유지하며(random 탐험 ❌)
- **죽음의 가치 차이**: 트레이드 킬을 만드는 죽음 = 팀 정보 / 버티다 죽는 것 = 가치 없음(원칙 7 연결)

**War Machine in Control (Maozin 대상, 전사문 5)**:
- B 사이트 방어용 미리 사용 ❌ — 적이 들어오게(let them in) 둔 후 undodgeable 상황에서 bombard
- 적이 6명 남아 play for lives → operator 써서 뚫으려 할 때가 war machine 타이밍
- statue 쪽이나 언덕 안에서 안전거리 확보 후 사용
- 적이 war machine을 알면 트로피 깔고 피함 → 선사용 무의미

**Standoff Control — B push 상세(전사문 5, 코치 그림 설명)**:
- B push가 핵심(A push는 fine). B를 위해 **statue control** 필요
- statue를 위해 **broken control** 필요
- broken을 위한 두 경로: (1) A 사이트 잡고 push (2) 차량 뒤에 숨어 left peek
- broken 제어를 위해 **top granny** 시야 차단 필요(스나이퍼 감시) — Maozin 스나이퍼가 top granny 감시
- **smoke statue + 2 tractor + 2 mid**: 3명이 smoke 덮고 statue push, 1명 control 감시, 스나이퍼 top granny
- top market은 초기 밸류 낮아 적이 안 둠 — SKS/스나이퍼 특별 전술 아니면
- **Sparrow 제안(Standoff B 한정)**: death machine 대신 sparrow로 B 폭격 → 클리어 → retake (코치 제안, Kingz 반발 예상)

**Crossroads Strike Control(전사문 5)**:
- 우리가 스폰에서 고전 + 1-2명이 적 진역 roaming → 그 선수의 잡은 **사이트를 캡처**해야(원칙 9 연결)
- 캡처하면 스폰 공격 중인 적이 뒤를 봐야 함 → 우리가 스폰에서 탈출 → 거기서 시작

## 스나이퍼 운용 원칙 (★ 전사문 9 신규)

> 코치가 Malzen(Mau5in) 스나이퍼 활용 논의에서 정립. "스나이퍼 = 보너스"라는 팀 인식이 케미스트리 문제를 만든다.

- **스나이퍼는 팀이 예측 가능한 위치에 있어야 한다**: 팀메이트가 "저기 있겠구나"라고 쉽게 예상하는 포지션(Standoff 기준 top blue / tractor 쪽). 예측 불가능한 위치의 스나이퍼 = 팀에게 4v5로 느껴짐
- **스나이퍼 있으면 미드 레인을 비워라**: 나머지 인원은 alley + B/attacker 두 레인 집중 → 스나이퍼에게 각도 제공 + 적 스폰킬 회피
- **캡처 전략 = 스나이퍼 유무로 결정**:
  - 스나이퍼 라인업 → **싱글 캡으로 충분**(시간 벌기) + play for tickets
  - AR 라인업(Mau5in이 AR 시) → 더블캡 노림
- **AR smoke의 목적(Standoff)**: 연막을 최대한 깔아 **적 스나이퍼를 고립**시키고, 적 스나이퍼를 무시한 채 지속적으로 트레이드킬을 빌드하는 것
- **맵별 선택**: Raid는 스나이퍼 go. Crossroads Strike는 기존 스크립트가 inconsistent해서 재검토 중(오래 박은 스크립트 폐기 논의)
- ⚠️ **미해결 과제**: "팀원 머릿속에서 스나이퍼=4v5" 인식 문제 — 코치가 Control 플레이 개선 과제로 명시적 보류 ("later on")

**흔한 실수**:
- B 사이트를 방어용으로 미리 옵스킬 사용 → 적 회피 → 낭비
- 버티다 죽음(가치 없는 죽음) 반복
- statue/broken 통제 없이 B push 시도 → 각에서 삭제
