## Hardpoint

★ v0.2 신규 (전사문 5)

| 힐        | 코치의 통찰                                                                                                                                                                                                                                                                                                                                                      | 출처       |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- |
| **P3** ★ | **top red 최우선 — Combine P3과 동일 원칙(전사문 5)**: P3 잡으면 무조건 top red 먼저, 시간·공간 있을 때 특히. top red 통제 = P3 통제 용이. initial kill은 언덕 안 적(먼저 회전한 놈)부터 — stretch out 금지. **lounge 고정 금지**: lounge 위치에서 flank 너무 걱정 → 킬 후 hill 쪽으로 포지션(스폰 가까이 → 팀 관련성). **2nd P3 catwalk spawn(전사문 5)**: catwalk 스폰이 잡히면 피할 수 없는 상황(in-inevitable) — lounge 적의 움직임은 어느 정도 감수.             | 전사문 5    |
| **P4**   | **slay out은 hill control 후에(전사문 5)**: Takeoff P4에서도 킬 후 언덕 점수 확보되면 stretch out ok — 24/7 언덕 안 고집 아님.                                                                                                                                                                                                                                                        | 전사문 5    |
| **P4** ★ | **거점과의 연관성(전사문 7)**: Takeoff는 스폰이 "개 그지 같아서" 계속 거점 안에 있어야 — **나와 거점의 물리적 거리가 매우 가까워야 함**. 꼭 스텝인 안 해도 "연관성"이 지척이어야. 거점을 잘 밟아주면 적이 급격히 들어와도 대처 가능. 너무 여유 생겼다고 stretch out 안 하는 건 좋았음. **뇌정지 주의(전사문 7)**: 너무 많은 각을 보려는 것(=불안)이 Takeoff에서 특히 문제 — P1/P2/P3가 멀고 루트가 복잡해서 미리 빼는 옵스킬이나 다방향 피킹이 효율이 안 나옴. **해결**: 봐야 할 각 중 일부를 포기하고 안전 지대(벽 기대고 한쪽만 째는)에서 다시 시작할 것. | 전사문 5, 7 |
