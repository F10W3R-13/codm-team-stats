# 전사문 흡수 작업

새 전사문을 분석하여 지식베이스에 통합한다. 이것은 코치의 지식을 외부화하는 세컨드브레인의 핵심 워크플로우다.

## 입력

전사문 파일: $ARGUMENTS

## 절차

### 1단계: 전사문 읽기
- 위 파일을 읽는다. 경로가 생략되었으면 `transcripts/` 폴더에서 찾는다.
- 파일을 찾을 수 없으면 사용자에게 위치를 물어본 후 중단한다.

### 2단계: 지식 구조 파악
- `knowledge/INDEX.md`를 읽는다.
- 현재 지식베이스의 전체 구조를 파악한다: 철학 원칙, 역학, 모드, 맵, 팀 운영, 흡수 로그.
- `knowledge/log/흡수로그.md`를 읽어 이미 흡수된 전사문 번호를 확인한다.

### 3단계: 전사문 분석
전사문을 읽고 다음을 추출한다:

**분석 틀:**

a) **철학적 통찰** (→ `principles/코칭철학원칙.md`에 갈 것인가?)
   - 코치가 반복적으로 강조한 신념인가?
   - 기존 원칙의 강화인가, 새 원칙인가?

b) **게임 역학 지식** (→ `mechanics/`에 갈 것인가?)
   - CODM의 작동 원리에 대한 통찰 (TTK, 스폰, 시야 등)
   - 무기/옵스킬 메타 변화
   - 새 공용어/개념

c) **맵/모드 전술** (→ `modes/` 또는 `maps/`에 갈 것인가?)
   - 특정 맵의 힐별 전술
   - 모드별 일반 역학
   - 어느 맵인가? (Combine, Hacienda, Takeoff, Summit, Arsenal, Standoff, Crossroads Strike)

d) **팀 운영** (→ `team/팀운영.md`에 갈 것인가?)
   - 콜 시스템, 역할 분배, 갈등 관리
   - 선수별 분석

e) **코칭 방법론 관찰**
   - 코치가 어떻게 피드백을 주었는가 (개인 비난 vs 구조적 원인)

### 4단계: 통합 — 해당 파일들에 내용 추가

각 분류된 통찰을 **해당 파일의 적절한 위치**에 통합한다.

**통합 원칙:**
- 기존 내용의 맥락에 맞는 위치에 삽입 (중복 회피)
- 모든 새 내용에 **출처 표시**: `(전사문 N)` 또는 `— 전사문 N`
- 기존 원칙을 강화하는 내용이면, 해당 원칙 아래에 "심화" 또는 "보강"으로 추가
- 완전히 새 원칙이면, 새 `## 원칙 N`으로 추가하고 기존 원칙들과의 관계 명시
- 맵 전술이면, 해당 맵 파일의 해당 P 섹션에 추가
- 무기/옵스킬 메타면, 선수별 표나 옵스킬 타이밍 섹션에 추가

**파일 경로 참조 (작업공간 기준):**
- 철학: `knowledge/principles/코칭철학원칙.md`
- 역학: `knowledge/mechanics/CODM기본역학.md`, `knowledge/mechanics/무기옵스킬메타.md`, `knowledge/mechanics/공용어사전.md`
- 모드: `knowledge/modes/Hardpoint.md`, `knowledge/modes/SearchDestroy.md`, `knowledge/modes/Control.md`
- 맵: `knowledge/maps/{맵이름}.md`
- 팀: `knowledge/team/팀운영.md`

### 5단계: 흡수 로그 갱신
`knowledge/log/흡수로그.md`에 새 항목을 추가한다:

```markdown
## 전사문 N — [제목/요약]

- **학습**: [이 전사문에서 무엇을 학습했는가]
- **철학 기여**: [어느 원칙에 기여했는가 / 새 원칙인가]
- **게임 지식**: [어떤 게임 지식이 추가되었는가]
- **코칭 관찰**: [코칭 방법론 관찰]
```

### 6단계: INDEX.md 갱신
`knowledge/INDEX.md`의 메타데이터를 갱신한다:
- 버전 번호를 올린다 (예: v0.2 → v0.3)
- "마지막 갱신" 날짜를 오늘로
- "기반 전사문"에 새 전사문 번호 추가 (예: "전사문 1-6" → "전사문 1-7")

### 7단계: 보고

작업 완료 후, 다음 형식으로 보고한다:

```
## ✅ 전사문 N 흡수 완료

### 추가된 내용
| 파일 | 추가 내용 | 분류 |
|---|---|---|
| principles/코칭철학원칙.md | 원칙 2 "Shadow" 강화 — ... | 철학 |
| maps/Combine.md | P3 새 통찰 — ... | 맵 전술 |
| ... | ... | ... |

### 새 원칙 (있는 경우)
- (새 원칙이 추가되었으면 요약)

### 버전
v0.X → v0.Y (기반 전사문 1-N)
```

## 주의사항
- 원본 전사문의 **뉘앙스와 코치의 목소리**를 보존하라. 단순 요약이 아니라 코치가 말한 핵심 통찰을 그대로 살려라.
- 코치의 원어 인용문이 있으면 따옴표로 보존하라.
- **새 내용을 창작하지 마라.** 전사문에 있는 것만 통합하라.
- 분류가 애매하면, 가장 적합한 파일을 판단하고 이유를 보고에 명시하라.
- 전사문 번호가 불명확하면(파일명에 없으면), 흡수 로그의 마지막 번호 + 1로 추정하라.
